# 練習11：フォームの単項目バリデーション

## 問題

プロフィールフォームとReact Hook Form・Zodの連携処理が実装されています。
入力欄とバリデーションエラーの表示は変更せず、`profileSchema`へ各項目のバリデーションを追加してください。

### 対象ファイル

[/src/exercises/11-single-field-validation/schema.ts](/src/exercises/11-single-field-validation/schema.ts)

### バリデーション要件

| プロパティ | 要件                                | エラーメッセージ                     |
| ---------- | ----------------------------------- | ------------------------------------ |
| `name`     | 前後の空白を除去した結果が1文字以上 | `名前を入力してください`             |
| `name`     | 30文字以下                          | `名前は30文字以下で入力してください` |
| `age`      | 整数                                | `年齢は整数で入力してください`       |
| `age`      | 18以上                              | `年齢は18以上で入力してください`     |
| `age`      | 120以下                             | `年齢は120以下で入力してください`    |

## 合格条件

以下のコマンドでアプリを起動し、ブラウザで`http://localhost:5173/#/exercise/11`を開いてください。

```bash
npm run dev
```

画面を操作し、以下のチェックリストをすべて満たすことを確認してください。

- [ ] 名前を空欄または空白文字だけにして「プロフィールを保存」を押すと、`名前を入力してください`と表示される
- [ ] 名前へ31文字以上入力して送信すると、`名前は30文字以下で入力してください`と表示される
- [ ] 30文字の名前の前後に空白文字を付け、入力全体が30文字を超えた状態で送信しても、`名前は30文字以下で入力してください`と表示されない
- [ ] 年齢へ小数を入力して送信すると、`年齢は整数で入力してください`と表示される
- [ ] 年齢へ17以下の値を入力して送信すると、`年齢は18以上で入力してください`と表示される
- [ ] 年齢へ121以上の値を入力して送信すると、`年齢は120以下で入力してください`と表示される
- [ ] 30文字以下の名前と18以上120以下の整数を入力して送信すると、フォームの下に保存成功の内容が表示される

## 解説・ヒント

フォームには`zodResolver(profileSchema)`が設定済みです。
そのため、`profileSchema`へ追加した条件とエラーメッセージは、フォーム送信時の検証と画面上のエラー表示へ反映されます。

文字列には`.trim()`、`.min()`、`.max()`を組み合わせられます。

```ts
const titleSchema = z
  .string()
  .trim()
  .min(1, { error: 'タイトルを入力してください' })
  .max(100, { error: 'タイトルは100文字以下で入力してください' });
```

数値には`.int()`で整数、`.min()`と`.max()`で範囲を指定できます。
フォーム側では`valueAsNumber: true`を設定しているため、年齢は文字列ではなく数値としてスキーマへ渡されます。
